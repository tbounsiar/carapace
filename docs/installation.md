# Installation

Download the file for your system from the [Download section of the README](../README.md#download). Release builds are not code-signed, so the first launch needs one extra confirmation on Windows and macOS.

## Windows

Windows 10 and 11, x64 or ARM64.

1. Run `carapace-windows-x64-setup.exe` (or `carapace-windows-arm64-setup.exe` on an ARM PC).
2. If SmartScreen shows "Windows protected your PC", choose **More info**, then **Run anyway**.
3. Follow the installer. Carapace is then in the Start menu.

The `carapace-windows-x64.msi` package installs the same app and suits deployment tools that expect an MSI. It is available for x64 only.

Carapace uses the Microsoft Edge WebView2 runtime. It ships with Windows 11 and current Windows 10; the installer downloads it if it is missing.

To uninstall, use Settings > Apps > Installed apps. Your data in `%USERPROFILE%\.carapace` and the saved passwords in Credential Manager are not removed; see [Removing all data](#removing-all-data).

## macOS

Apple Silicon (`carapace-macos-arm64.dmg`) or Intel (`carapace-macos-x64.dmg`).

1. Open the `.dmg` and drag **Carapace** to **Applications**.
2. Open Carapace. macOS refuses because the app is not notarized: it is only ad-hoc signed.
3. Open System Settings > Privacy & Security. Near the bottom, a message says Carapace was blocked. Choose **Open Anyway** and confirm with your password.
4. Open Carapace again and confirm **Open**.

Instead of steps 2 to 4 you can remove the quarantine flag from a terminal:

```
xattr -dr com.apple.quarantine /Applications/Carapace.app
```

Passwords and passphrases go to your default keychain (usually the login keychain). If macOS asks whether Carapace may use a keychain item, allow it.

## Linux

x64 or ARM64. Three formats are published; pick one.

### AppImage

Runs without installing.

```
chmod +x carapace-linux-x64.AppImage
./carapace-linux-x64.AppImage
```

AppImages need FUSE 2. If the AppImage does not start and mentions `libfuse.so.2`, install it:

```
sudo apt install libfuse2        # Ubuntu 22.04, Debian
sudo apt install libfuse2t64     # Ubuntu 24.04 and later
sudo dnf install fuse-libs       # Fedora
```

### Debian, Ubuntu (.deb)

```
sudo apt install ./carapace-linux-x64.deb
```

Remove it with `sudo apt remove carapace`.

### Fedora, RHEL, openSUSE (.rpm)

```
sudo dnf install ./carapace-linux-x64.rpm
```

On openSUSE use `sudo zypper install ./carapace-linux-x64.rpm`.

Replace `x64` with `arm64` in the file names on an ARM64 machine.

### Keychain on Linux

Carapace stores passwords and passphrases through the freedesktop Secret Service API. A provider must be running and unlocked in your session:

- GNOME and most GTK desktops: GNOME Keyring (`gnome-keyring`), usually running already.
- KDE Plasma: KWallet, with its Secret Service support enabled.

Without a provider, saving or using a stored secret fails with a message asking you to unlock or enable the system keychain. See the [FAQ](faq.md#the-keychain-is-unavailable-on-linux).

## Updating

Download and install the new release over the old one. Your hosts, keys and settings are kept: they live in the data folder, not in the app.

## Removing all data

Uninstalling leaves your data in place. To remove it as well:

1. Delete the data folder: `~/.carapace` (`%USERPROFILE%\.carapace` on Windows), or the folder `$CARAPACE_HOME` points to. Keys generated by Carapace are in its `keys/` subfolder; back them up first if servers still trust them.
2. Delete the keychain entries of the service `org.tbounsiar.carapace`:
   - Windows: Credential Manager > Windows Credentials, entries ending in `.org.tbounsiar.carapace`.
   - macOS: Keychain Access, search for `org.tbounsiar.carapace`.
   - Linux: Seahorse ("Passwords and Keys") or KWalletManager, search for `org.tbounsiar.carapace`.

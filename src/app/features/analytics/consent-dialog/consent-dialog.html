Carapace can send anonymous usage events to help decide what to improve.

Sent

  • Which features you use, like opening a terminal or a transfer finishing
  • App version, operating system and language
  • Error codes when a connection fails

Never sent

  • Host names, addresses, ports or usernames
  • File names, paths, keys or passwords
  • Names of your projects, hosts or variables
  • Error messages or anything you type

There is no account and no tracking ID. You can change this any time in Settings.
